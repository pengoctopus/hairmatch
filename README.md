## 技术栈

- **React 19** + **Vite**
- **React Router** 单页应用路由
- **GSAP** 动画效果
- 部署在 **Netlify**

## 本地开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

构建产物输出到 `dist` 目录。
